🏥 Hospital LIS & OPD Management System

A Streamlit-based Digital Health application designed to simulate a Hospital Laboratory Information System (LIS) integrated with OPD (Outpatient Department) workflows. The system supports patient management, lab test processing, OCR-based report extraction, multilingual support, and basic clinical data handling.

🚀 Features

👤 Patient Management
- User registration and authentication
- Patient data storage using CSV/JSON
- Secure handling of user credentials (hashed passwords)
  
🩺 OPD System
- Patient visit logging
- OPD record management
- Structured patient history tracking
  
🧪 Laboratory Information System (LIS)
- Lab test request handling
- Lab report storage and retrieval
- Integration with LOINC mapping for standardized test codes
  
📄 OCR-Based Report Processing
- Upload lab reports (images/PDFs)
- Extract text using Tesseract OCR
- Process and structure extracted medical data
  
🌐 Multilingual Support
- Translation using GoogleTranslator
- Enables accessibility for non-English users
  
🔊 Text-to-Speech
- Convert extracted or generated text into audio using gTTS
  
📊 Data Handling
- Uses Pandas for structured data operations
- JSON/CSV-based lightweight storage system
